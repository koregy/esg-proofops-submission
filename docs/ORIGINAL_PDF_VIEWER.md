# Original PDF source viewer (W16)

The hosted result opens a claim/PDF split view by default. Every result source link targets this viewer; the result UI no longer mounts `SourcePageView` or requests the server PNG endpoint. W15 summary, terms, analysis scope, status filters and detailed grading panels remain intact.

`HostedAnalysis` prefers the authenticated result URL so additive `w16_source_document` and `w16_source_view` metadata is available. `originalPdfUrl` constructs a same-API route from validated document ID/SHA rather than trusting a payload URL. Existing saved results without this metadata show an explicit unavailable-source message. No public original URL, localStorage source cache or service-worker source cache is created.

`pdfjs-dist` 5.4.394 was already pinned in this repository (Apache-2.0); no dependency or lockfile version changed. `prepare-pdf-assets.mjs` copies that package's WASM codecs, CMaps, standard fonts and licenses into ignored `public/pdfjs/` during dev/build. This is required for image-heavy PDFs such as LG's JPEG2000 pages and avoids CDN requests. The worker is bundled with `?url`; the viewer chunk loads lazily. Build with `VITE_ANALYSIS_BACKEND=hosted` for the hosted deployment, as before.

PDF.js requests use credentials, 1 MiB byte ranges, disabled streaming and auto-fetch. One current-page canvas is rendered; stale render tasks are cancelled and page resources cleaned up. Canvas resolution is capped. Zoom/resize reveal the selected quote; stored top-left rotated crop-box coordinates are normalized once and must match the actual PDF viewport. Missing coordinates remain explicit. Exact line rectangles are preferred, followed by glyphs, then stored source-region boxes. Separately stored table cells take precedence over an enclosing table box. Yellow represents claim references; blue represents the selected element reference, with its element code and quote shown outside the PDF.

Use native page/zoom/fit controls, search, pointer hover, keyboard focus/Enter, evidence jump chips and a previous-page button. Mobile list/PDF buttons switch the pane; selecting a claim focuses the PDF pane. Current-page claims are marked in the list. Loading/progress, expired/unavailable sources, integrity failure, encrypted PDFs and coordinate mismatch have distinct messages. Original quote text remains accessible outside the canvas; embedded PDF annotation interaction, XFA and eval are disabled.

Verification: `pnpm --filter proofops-web typecheck`, `VITE_ANALYSIS_BACKEND=hosted pnpm --filter proofops-web build`, `pnpm --filter proofops-web test:hosted`, plus Playwright against the local authenticated backend with actual saved LG results. W16 artifacts record p36 ISO 14001 three-line claim/two-line M2 evidence, p41 value/unit/year cells, mobile/desktop/keyboard, injected error states, a UI-only cross-page association, and a separate synthetic 150 MB/300-page range benchmark. The latter does not measure rendering cost of 300 image-heavy pages. The available saved LG results do not contain accepted different-page element evidence, so the report does not claim semantic validation of such an association.

W17 distinguishes highlight precision using the existing W16 geometry: exact line/glyph rectangles and stored table cells retain their fills; paragraph-only regions have unfilled dashed outlines and the legend/status “영역 표시(정확 위치 아님)”. SVG titles expose the same distinction. Coordinates are never estimated from quote text. Selected mobile tabs keep white text on `#215e46`, including hover/focus and either system color scheme; tab color transitions are disabled to avoid low-contrast intermediate states.
